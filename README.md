# De sono ad verbum

Sitio web del Trabajo Fin de Grado *De sono ad verbum: la activación léxica a través de la música instrumental*.

## Cómo está publicado

Este repositorio contiene un único archivo, `index.html`, que es la web completa (incluye el audio del EP incrustado). GitHub Pages lo sirve directamente sin necesidad de ningún proceso de compilación.

## Actualizar la web

1. Sustituye `index.html` por la versión nueva (arrastrar y soltar en GitHub, o `git add`/`commit`/`push` si usas Git en local).
2. GitHub Pages se actualiza solo, normalmente en uno o dos minutos.

## Activar / comprobar GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
